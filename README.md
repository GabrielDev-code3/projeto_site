# Projeto Site 🌐

> Projeto prático desenvolvido para treinar versionamento de código e fluxo de trabalho com Git e GitHub.

## 💻 Sobre o projeto
O **Projeto Site** é uma aplicação simples criada exclusivamente com propósitos educacionais. O foco principal deste repositório não é a complexidade do código em si, mas sim a aplicação prática de comandos Git (commits, branches, merges) e a familiarização com o ambiente do GitHub.

## 🛠️ Tecnologias e Ferramentas Utilizadas
* **Git:** Para o controle de versão local.
* **GitHub:** Para hospedagem do repositório e prática de trabalho remoto.
* HTML5, CSS3
## 📚 O que foi praticado
Durante o desenvolvimento deste repositório, os seguintes conceitos foram aplicados:
- Criação e clonagem de repositórios.
- Fluxo básico do Git (`add`, `commit`, `push`, `pull`).
- Resolução de conflitos de merge.
- Criação de ramificações (`branch`) para o desenvolvimento de novas features isoladas.
